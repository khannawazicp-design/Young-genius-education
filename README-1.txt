1. supabase.com: create project. Authentication > Providers > Email: turn OFF sign-ups. Authentication > Users > Add user (your email + strong password).
2. Open supabase.sql, replace YOUR_EMAIL_HERE with that email, paste in SQL Editor, Run.
3. Project Settings > API: copy Project URL and anon public key into config.js.
4. Upload index.html, admin.html, style.css, config.js to GitHub, then enable Pages. Admin is at yoursite/admin.html
